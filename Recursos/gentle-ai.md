# Gentleman Programming / gentle-ai — dossier

> Nota de referencia. Gentleman Programming (Alan Buscaglia) es la fuente de ODD, RDD y de la frase "verifying beats generating", usadas en la Charla 23.

## Qué es

**Gentleman Programming** es la comunidad hispanohablante de Alan Buscaglia centrada en desarrollo asistido por IA. **gentle-ai** es el framework/CLI que construye sobre Claude Code / Copilot CLI, inyectando disciplina de "AI harness engineering" encima del modelo base.

No hace falta instalar gentle-ai para usar sus ideas: la mayoría son instrucciones persistentes que se pueden escribir a mano en `CLAUDE.md` o `copilot-instructions.md`.

## Lo que aporta a esta serie

- **[[odd|ODD — Organic Driven Development]]** — el comportamiento por defecto del agente (autorizar → explorar → clasificar → documentar si es sustancial)
- **[[rdd|RDD — Receipt-Driven Development]]** — modelo de profundidad para revisión de código (4R: Risk, Resilience, Readability, Reliability)
- El término **[[ai-harness-engineering|AI harness engineering]]** y la frase *"verifying beats generating"*, usados como cierre de la Charla 23

## Relación con el resto del arnés

ODD y RDD no sustituyen nada de lo ya construido en la serie ([[sdd|SDD]], [[bdd|BDD]], Skills, MCPs) — son el nombre formal para disciplinas que ya se venían aplicando, más el protocolo concreto para lo que no tenía nombre todavía (qué hacer cuando no hay spec ni escenario).
